# 💸 App de Organização de Finanças Pessoais com Vibe Coding

Este projeto foi desenvolvido como um Desafio de Projeto da DIO de Vibe Coding utilizando o Lovable e o Copilot Web. A proposta é criar um aplicativo de organização financeira pessoal baseado em interações em linguagem natural.

📝 PRD Refinado no Copilot Web
Crie um App de Finanças Pessoais com base no seguinte PRD (Product Requiremts Document).
PRD – Aplicativo de Organização de Finanças Pessoais via Conversa


```markdown
1. Contexto
Criar um aplicativo que permita ao usuário organizar suas finanças pessoais por meio de conversas naturais, sem depender de formulários complexos ou planilhas.
O objetivo é tornar o controle financeiro mais acessível, simples e envolvente.

2. Problema
- Apps tradicionais exigem muita entrada manual de dados.
- Pouca personalização e experiência engessada.
- Usuários iniciantes acabam desistindo do controle financeiro.

Solução proposta: oferecer uma experiência conversacional com recomendações automáticas de economia, construída com Design Universal, garantindo que o aplicativo seja inclusivo e proporcione boa experiência para o maior número possível de usuários.

3. Público-Alvo
- Pessoas que querem começar a organizar suas finanças sem complicação.
- Usuários iniciantes em controle financeiro.
- Pessoas que preferem interações simples e naturais em vez de interfaces tradicionais.
- Usuários diversos, incluindo aqueles com diferentes níveis de letramento digital, necessidades de acessibilidade ou preferências de interação.

4. Funcionalidades-Chave
1. Registro de gastos via chat em linguagem natural.
2. Classificação automática das transações (alimentação, transporte, lazer etc.).
3. Definição e acompanhamento de metas financeiras (ex.: guardar R$200/mês).
4. Agente Financeiro que envia dicas de economia personalizadas.
5. Relatórios simples e visuais para acompanhar evolução e hábitos de consumo.
6. Design Universal aplicado: interface acessível, linguagem clara, suporte a diferentes perfis de usuários e compatibilidade com recursos de acessibilidade (ex.: leitores de tela).

5. Entregável da IA
- Plano de MVP contendo:
  - Principais telas (chat, metas, relatórios).
  - Recursos necessários (NLP para entender linguagem natural, categorização automática, motor de recomendações).
  - Esboço de validação inicial (testar com grupo diverso de usuários iniciantes e com diferentes necessidades).
- Linguagem acessível e educativa em português.
```

🔍 Funcionalidades do App de Organização Financeira
1. Dashboard Financeiro

    Exibe um panorama claro das finanças pessoais:
        Receitas: Total de ganhos registrados
        Despesas: Total de gastos
        Saldo: Diferença entre receitas e despesas
    Interface simples e direta para facilitar a compreensão

2. Assistente Financeiro
    Personagem conversacional que interage com o(s) usuário(s)
    
3. Registro de Transações via Chat
    Campo de entrada para o usuário digitar mensagens
    Permite registrar gastos

4. Metas Financeiras
    Área dedicada à criação e acompanhamento de objetivos financeiros
    Botão para adicionar novas metas

5. Relatórios Personalizados
    Visualizações simples e adaptadas ao estilo do(s) usuário(s)
 
6. Design Universal
    Interface acessível e inclusiva:
    Linguagem simples
    Navegação clara
